# Prisma ORM 7.8.0 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebase Vetching Corporation의 사내 Prisma fork (prisma + prisma-engines)를 upstream 7.8.0 위로 올리고, multi-tenant/read-replication/forceWriter 커스텀 코드를 v7 API에 맞게 재적용한다.

**Architecture:** prisma-engines(Rust)를 먼저 리베이스하여 커스텀 WASM을 빌드한 뒤, prisma(TypeScript)를 4개 Phase로 나누어 리베이스한다. 각 Phase 완료 시 사용자 승인 게이트를 거친다. 핵심 충돌 지점은 `getPrismaClient.ts`, `ClientEngine.ts`, `LocalExecutor.ts`(TS)와 `compiler.rs`, `context.rs`(Rust).

**Tech Stack:** TypeScript, Rust, WASM (wasm-bindgen), pnpm, git rebase

**Spec:** `docs/superpowers/specs/2026-05-21-prisma-7.8.0-upgrade-design.md`

v7 `Context` 구조체 (base 기준, 63줄):


추가할 내용:

```rust
use crate::dynamic_schema::DynamicSchema;

pub struct Context<'a> {
    connection_info: &'a ConnectionInfo,
    traceparent: Option<TraceParent>,
    max_insert_rows: Option<usize>,
    max_bind_values: Option<usize>,
    alias_counter: AtomicUsize,
    dynamic_schema: DynamicSchema,  // 추가
}
```

`new()` 메서드의 `dynamic_schema` 필드 초기화:

```rust
impl<'a> Context<'a> {
    pub fn new(connection_info: &'a ConnectionInfo, traceparent: Option<TraceParent>) -> Self {
        // ... 기존 코드 ...
        Self {
            // ... 기존 필드 ...
            dynamic_schema: DynamicSchema::default(),
        }
    }

    pub fn new_with_dynamic_schema(
        connection_info: &'a ConnectionInfo,
        dynamic_schema: DynamicSchema,
        traceparent: Option<TraceParent>,
    ) -> Self {
        let mut ctx = Self::new(connection_info, traceparent);
        ctx.dynamic_schema = dynamic_schema;
        ctx
    }

    pub fn resolve_schema(&self, origin_schema: &str) -> Option<String> {
        if self.dynamic_schema.is_empty() {
            return None;
        }
        self.dynamic_schema.get(origin_schema).map(|s| s.to_owned())
    }
}
```

```typescript
    let driverAdapterReplica: SqlDriverAdapter | undefined
    let transactionManager: TransactionManager | undefined

    try {
      driverAdapter = await options.driverAdapterFactory.connect()
      if (options.driverAdapterReplicaFactory) {
        driverAdapterReplica = await options.driverAdapterReplicaFactory.connect()

        plugins: this.#options.sqlCommenters,
        queryInfo,
      },
    })
```
